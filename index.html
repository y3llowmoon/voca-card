JSON 배포 파일

자료는 브라우저에 저장됩니다. JSON을 내려받아 index.html 옆의 decks.json을 교체하고 Git에 커밋한 뒤 Push하면 배포됩니다.

자료를 불러오는 중입니다.

파일 교체 후 다시 불러오면 변경을 확인할 수 있습니다. 배포 예: git add decks.json → git commit -m "Update vocabulary data" → git push

브라우저 저장 자료를 JSON으로 내려받아 배포할 수 있습니다.
